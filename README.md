# reFrame Camera for Android

**Версия 1.0.0**

Порт экспериментальной камеры **reFrame** (на основе дисплея Waveshare Spectra 6 ePaper) на Android: превращает ваши фото в изображение в стиле электронных чернил.

> Оригинальный проект: [reframe.camera](https://reframe.camera) | [GitHub reframe](https://github.com/kaloyaan/reframe)

## 📥 Скачать

- **Готовый APK**: [страница GitHub Releases](https://github.com/purkalolka/reframe-camera-android/releases/latest) (файл `app-release.apk`).
- **Всегда свежая сборка**: [Actions → Build Android APK → Artifacts](https://github.com/purkalolka/reframe-camera-android/actions) — автоматически при каждом пуше в `main`.

**Требуется:** Android 5.0 (API 21) и выше.

**Установка:**
1. Скачайте `app-release.apk` с [Releases](https://github.com/purkalolka/reframe-camera-android/releases/latest).
2. Разрешите установку из этого источника в настройках Android («Неизвестные источники»).
3. Откройте APK и подтвердите установку. Приложение работает полностью офлайн.

## ✨ Как пользоваться

1. Выберите переднюю или заднюю камеру, доступна вспышка.
2. Наведите и снимите (кнопка — ниже кадра).
3. Или импортируйте любое фото из галереи — эффект применяется так же, как и к снимку камеры.
4. Настройки (шестерёнка): палитра, режим дизеринга (Floyd-Steinberg / Bayer), плотность, контраст, скорость «проявки» на дисплее.
5. Результат: сохранение в альбом «reFrame» в галерее или «Поделиться».

## ⚙️ Под капотом

1. **Палитра Blended Spectra-6** — 6 пигментов электронных чернил (чёрный, белый, красный, зелёный, синий, жёлтый) с факторным смешиванием, коррекцией яркости (×1.1) и сочности (×1.4).
2. **Два движка дизеринга**: Floyd-Steinberg (с демпфированием ошибки — без выбивания белых) и Ordered Bayer 4×4 с расстояниями в пространстве CIELAB (ΔE²).
3. **Анимация «ePaper Refresh»** — пятифазная симуляция физической переполюсовки микрокапсул (мерцание, зачистка, укладка пигментов). Настройка скорости: 1.5–6.0 с.
4. **Фоновый изолят** — расчёты дизеринга выполняются отдельно от интерфейса, UI не подвисает. Настройки (палитра, плотность, режим, скорость) сохраняются между запусками.
